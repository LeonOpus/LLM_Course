# 整合恢复版 M19B：交付规格

解决的问题：新手恢复完整前后端需要合并多个包及接口契约，容易遗漏。本交付提供已经整合的参考代码，供新目录恢复；逐节 SDD/TDD 学习路径保留。

## 输入与输出

- 代码只从 release-m19b-inputs.json 锁定的实际阶段 ZIP 读取，不读取当前教师业务代码冒充旧阶段。
- 基础后端为 M10、评估为 M11，按清单顺序合并 reference；明确补齐 health 和 rerank 请求契约。每次字符串变换恰好匹配一次，否则停止。
- 资料通过已验证的 M04/M06 学生材料导出器生成：36 原件、6 变体、140 开发题、20 冒烟问题。60 保留题正文和答案不分发。
- 输出独立 ZIP、文件 SHA256 清单、输入包摘要、中文启动指南、只读文件核查命令、验证报告。不带密钥、运行数据、依赖缓存、教师个人路径。
- 新手解压至新目录即可按启动指南安装锁定依赖、启动前后端、验证 CSV 解析，再按课程配置真实服务。不要把恢复参考代码称为学生本人完成的 TDD。

## 验收

1. 错误 ZIP 摘要、重复条目、越界路径、符号链接、敏感文件、契约替换未匹配时拒绝；原输入包不变。
2. 完成版含实际后端、完整前端、评估工具及固定演练材料，非空壳；没有远程调用或质量分数的伪造默认值。
3. 从交付 ZIP 解压到独立临时目录，重新安装 Python 和 npm 锁定依赖，运行全部随包后端/评估/前端测试与构建。
4. 新目录实际启动后端，验证健康配置、CSV 上传/解析/预览与空库回答。CLI 和 HTTP 证据分别记录。
5. 覆盖表、质量对比和 Windows 实机状态如实标记。macOS 成功不等于 Windows 安装已验证。

## SDD/TDD

先验证恢复程序拒绝损坏/不安全输入及意外契约状态，再实现恢复；业务程序仍使用阶段原有测试。发布代码完整性与 RAG 语义质量分开验收。固定响应演练无需密钥，真实对比必须另行调用云服务。
