# M10 / 问答生成、流式状态与引用校验

继承5.4的AC-07/AC-08和M09索引约束。目标：从本次真实检索候选选择上下文，调用百炼生成，展示有来源的回答及诊断记录。基线不增加重排策略或质量分数。

## 固定配置与上下文

- 检索复用M09的Pipeline.retrieve，必须检查索引manifest与查询Embedding匹配，不能绕过ready过滤。
- top_k=10，final_k=5，正文预算6000字符。保持候选顺序，不截断片段；超出预算跳过并记录char_budget，超过条数记final_k。重复chunk_id拒绝。
- 6000只计算片段正文；不是完整提示词token预算。消息中还有问题、来源、元数据、系统要求和可选历史。
- qwen-plus，temperature=0，enable_thinking=false，max_tokens=2048，JSON模式；prompt_version=rag-m10-v1。配置不是最优值或质量保证。
- 历史最多6条、合计6000字符，仅user/assistant。历史辅助理解，不当作证据；当前基线查询仍为当前问题，不做指代改写。

## 回答契约

模型输出status/answer/citation_ids；status为answered/refused/clarify。非空文字，answered必须有引用。所有引用必须来自本次最终上下文，来源位置由后端映射，不接受模型自己编写的位置。

validation.format、citation_membership通过不等于semantic_support通过，后者固定not_evaluated，留给真实评估。usage缺失为未知，不补0。finish_reason非stop、流没有DONE、非法JSON、错误引用都不生成正式答案。

空最终上下文本地拒答，不调用生成模型。模型返回缺资料/缺条件的判断属于待评估输出，不宣称关键词规则能替代判断。

## HTTP与流

- POST /api/ask：非流式兼容接口，返回结果、run_id、timing、trace；错误502包含run_id与stage。
- POST /api/ask/stream：真实SSE事件；phase→context→draft→result或error。draft为未校验模型JSON片段，不是最终答案。没有对已完成答案做打字动画。
- GET /api/traces/{run_id}：仅32位小写hex编号，其他404。显示本次运行，不展示凭证。
- history、问题、final_k在HTTP响应开始前验证，错误422；已经开始的流以error事件说明失败，不伪装成result。

## 运行记录

先建立run_id与trace文件；保存候选、重排栏（基线null）、最终上下文、预算排除原因、配置/提示词版本、耗时、状态、错误阶段。流草稿保存为raw_model_output并标明未校验；正式结果独立保存。生成失败仍保留检索与上下文。

取消时前端AbortController停止接收、请求序号阻止旧回包覆盖新状态；后端迭代器退出时关闭上游并记cancelled。正在执行的同步网络读取需要先返回，不能保证点击时立即停止云计算/计费。单机教学不实现生产任务队列。

## 前端

保留上传、解析、原件核对、入库与候选面板。新增问题框、检索并回答、停止接收、可选最近对话、清空历史、结果状态、引用原文/位置/原件链接、上下文调试、原始JSON草稿。

新请求清空旧答案；错误/取消不能冒充成功。正文和草稿使用文本渲染，不执行模型HTML。保留主题图/images/equipment-knowledge-hero.png。
