# M12D：把已核对的跨页结构接到实际索引

在M15A完整后端基础上增量接入M12C；不覆盖旧阶段恢复包。

- 新增CHUNK_STRATEGY=multipage_rows / multipage_context，对应P2 / P2+C2。默认baseline、简单表格策略不变。
- 全部优化索引仍须prepare_index_experiment创建不存在的独立runtime与随机collection。新策略预检实际块与版本2计划，冻结原件/解析块/计划指纹；先预检再付费或创建目标。
- 不含适用续表的文档允许显式groups=[]，需非空review_note与匹配指纹；保持B0切法。不能缺计划自动跳过，也不能将非PDF伪装成PDF。新索引清单逐文档写reviewed_table_count，0表示该文档无选定表格。
- 预览、实际Embedding文本、chunks缓存和索引清单必须一致。新算法版本m12c-multipage-v1，计划版本2，窗口600、普通块重叠100；禁用说明的策略不受超长未使用说明预算影响。
- retrieve和ask trace携带实际index_profile；评估器接受新策略并校验其算法/计划版本与固定预算。配置或内容漂移失败，不能只更改标签假称已切换。
- 多页source_spans经Milvus持久化与检索后逐字相同；保持主locator只代表主体行。全量候选的传输测试可用明确标注的人工向量；不得算成百炼语义召回或模型准确率。
- 列出可复制命令及环境变量切换、预览/入库/检索/评估顺序。原生PDF样例只做通路验证；正式评估必须从真实DocMind解析或经来源核对的修复快照开始。
