# B01（后端内部开发批次） 后端基础契约

本阶段先验证本地确定性逻辑，再接云服务。以下测试通过不表示 DocMind、百炼或完整 RAG 已跑通。

## 输入、输出与不变量

| 功能 | 输入 | 必须满足 |
|---|---|---|
| 来源定位 | 类型及定位字段 | PDF 页码、PPT 页号从 1 开始；拒绝布尔值充当页码；Office 不编造 PDF 页码 |
| 固定窗口切块 | 带来源的解析块 | 不跨来源合并；保留原文字符区间、块 ID；窗口重叠严格小于窗口 |
| 结构切块 | 带类型的解析块 | 表格作为完整候选；超限明确报错，后续实现按行拆表，不能悄悄截断 |
| 重排映射 | 原候选、服务返回 index | 按 index 取原候选；拒绝重复、越界、不合法分数 |
| 证据召回 | gold evidence IDs、命中证据 IDs | 去重后计算 Recall；无证据题不计入召回分母 |
| 状态迁移 | 当前状态、目标状态 | uploaded→parsing→parsed→indexing→ready；失败后显式重试；ready 只能在入库完成后写入 |

## TDD 执行

1. 先运行 `python -m unittest discover -s tests -v`，保存失败输出。
2. 在相同测试上实现功能，重新运行并保存成功输出。
3. 不改断言来迁就实现；云接口测试另行标识 fixture 或 live。

来源定位 `block_id` 是每种格式的最低定位保证。额外可靠字段有 PDF page、PPT slide、Excel sheet/cell_range、文本 line_start/line_end、DOCX heading_path。字段缺失表示精度降低，前端必须如实显示。
