# 从这里开始

你手上的这个文件夹，就是一个真实项目开工时你会从产品经理那里拿到的全部东西。

```text
RAG实操课程/
├── 从这里开始.md              ← 现在在读的
├── 01-项目任务书/
│   ├── 业务背景.md            公司、产品、售后的痛点、要交付什么
│   ├── 产品需求.md            五个页面、每个功能、默认参数、不做什么
│   ├── 验收标准.md            怎么算做完了、怎么算做好了
│   ├── 验收题集/              140 道带答案的验收题，20 道冒烟题
│   └── 页面原型/index.html    可点击的页面原型，用浏览器打开
└── 02-知识库资料/
    ├── 资料清单.md            36 份资料是什么、怎么分组
    ├── 产品手册与选型/
    ├── 安装维护与故障处理/
    ├── 售后政策与服务规程/
    ├── 配件与报价/
    ├── 工单记录与咨询/
    └── 格式对照变体（后续实验用）/
```

## 三步开始

1. **先花 20 分钟读任务书。** 顺序：业务背景 → 用浏览器打开页面原型点一遍 → 产品需求 → 验收标准。不用记住细节，知道要做什么就行。
2. **打开学习网站的模块六「RAG 从零实操」。** 第一课会带你装好编程助手（Claude Code 或 Codex），并把课程的 tutor 服务接上。
3. **在编程助手里说"开始 RAG 实操课程"。** 之后的每一步由 tutor 带着你走：告诉你现在做什么、为什么、做完怎么检查。

## 两个不要

- 不要把 `01-项目任务书` 里的验收题和答案当资料传进知识库。
- 不要改 `02-知识库资料` 里的文件名，验收题靠编号定位原件。

## 你会用到的两个对话框

| 对话框 | 用来干什么 |
|---|---|
| 编程助手（Claude Code / Codex） | 安排开发：写规格、写测试、写代码、跑命令、排错 |
| 你自己做出来的知识库网页 | 问业务问题："X200 在 42°C 能连续运行多久" |

前者是你的开发搭档，后者是你要交付的产品。全程别弄混。
